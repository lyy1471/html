SyncFlow 隐私政策

更新日期：2026 年 6 月 23 日  |  生效日期：2026 年 6 月 23 日

SyncFlow（以下简称"本应用"）由SyncFlow 开发团队（以下简称"我们"）开发并运营。我们深知个人信息对您的重要性，并将按照法律法规要求，采取相应的安全保护措施，尽力保护您的个人信息安全可控。

请您在使用本应用前仔细阅读并充分理解本隐私政策。如您不同意本政策的任何内容，请立即停止使用本应用。继续使用即表示您已充分理解并同意本政策的全部内容。

一、我们如何收集和使用您的个人信息

本应用仅在您主动使用对应功能时收集必要信息，核心数据仅在局域网内传输，不会上传至任何远程服务器：

1.1 设备发现与连接

  • 收集信息：设备名称、IP 地址、局域网广播地址
  • 使用目的：在局域网内发现其他安装本应用的设备并建立数据传输连接
  • 使用范围：仅在您的局域网内使用，不对外传输

1.2 文件传输

  • 收集信息：文件内容、文件名、文件大小、MIME 类型
  • 使用目的：在您主动选择并确认后，在局域网设备间传输文件
  • 使用范围：传输完成后临时缓存自动清理，数据不会上传至远程服务器

1.3 剪切板同步

  • 收集信息：剪切板文本内容
  • 使用目的：仅在您启用剪切板同步功能后，在局域网设备间同步剪切板内容
  • 使用范围：仅局域网内同步，默认关闭

1.4 屏幕投屏

  • 收集信息：屏幕图像数据
  • 使用目的：在您主动开启投屏功能后，将屏幕内容传输至局域网内其他设备
  • 使用范围：仅在投屏会话期间使用，停止后立即清除

1.5 应用配置与购买状态

  • 收集信息：主题偏好、语言设置、端口配置、购买状态
  • 使用目的：保存您的应用使用偏好和购买信息
  • 存储位置：仅存储在您的设备本地，使用系统级加密存储

二、设备标识与第三方 SDK

为保障应用功能实现和统计分析，我们集成了以下第三方 SDK。这些 SDK 可能因功能需要收集您的部分设备信息。

重要提示：以下第三方 SDK 均仅在您同意本隐私政策后才会初始化，未同意前不会收集任何信息。

2.1 友盟+ 移动统计 SDK

  • SDK 名称：友盟+ 移动统计 SDK（UMeng Analytics）
  • 服务商：友盟同欣（北京）科技有限公司
  • 使用目的：应用使用情况统计分析、崩溃分析
  • 收集信息类型：设备标识符（IMEI/Android ID/IDFA/OPENUDID/GUID）、MAC 地址、IP 地址、设备型号、操作系统版本、应用启动次数、页面访问时长、应用崩溃日志
  • 收集方式：SDK 自动采集
  • 隐私政策：https://www.umeng.com/page/policy

2.2 友盟+ 开屏广告 SDK

  • SDK 名称：友盟+ U-AppWin 开屏广告 SDK
  • 服务商：友盟同欣（北京）科技有限公司
  • 使用目的：开屏广告展示（仅面向非付费用户）
  • 收集信息类型：设备标识符（OAID/GAID）、设备型号、操作系统版本、屏幕尺寸
  • 收集方式：SDK 自动采集
  • 隐私政策：https://www.umeng.com/page/policy

2.3 华为 HMS 应用内支付 SDK（仅 Android）

  • 收集方式：SDK 自动采集（仅在发起购买流程时）
  • 隐私政策：https://consumer.huawei.com/cn/privacy/privacy-policy/

2.4 华为 AGC 基础服务 SDK（仅 Android）

  • SDK 名称：华为 AppGallery Connect Core SDK
  • 服务商：华为软件技术有限公司
  • 使用目的：提供华为应用市场基础服务（应用内支付依赖项、应用使用情况统计分析）
  • 收集信息类型：应用信息（包名、版本号）、设备标识符（OAID/AAID）、应用使用数据（启动次数、页面访问、操作行为）
  • 收集方式：SDK 自动采集
  • 隐私政策：https://consumer.huawei.com/cn/privacy/privacy-policy/

2.5 华为 AppGallery 版本更新 SDK（仅 Android）

  • 收集信息类型：应用包名、当前版本号、设备标识符
  • 收集方式：SDK 自动采集

  • 隐私政策：https://www.apple.com/legal/privacy/

三、系统权限申请与使用

本应用在提供以下功能时会向您申请相应权限。您可以随时在设备设置中管理或撤销这些权限。

  • 网络权限：用于局域网设备发现、数据传输、HTTP 服务器功能。本应用的核心功能依赖此权限。
  • 存储/媒体访问权限：用于您选择文件进行传输，以及将接收的文件保存到设备存储。Android 13+ 使用细粒度媒体权限（图片/视频/音频分别授权）。
  • 相机权限：用于扫描二维码以快速建立设备连接。仅在您主动使用扫码功能时申请。
  • 屏幕录制/投屏权限：用于将您的屏幕内容实时投射到局域网内其他设备。每次使用前均需您明确授权，且系统会显示明显提示。
  • 前台服务权限：用于后台文件传输和屏幕录制，确保应用在后台时这些功能仍能正常运行。通知栏会显示正在运行的服务。

关闭上述权限可能会影响对应功能的正常使用，但不会影响应用的其他功能。

三-A、传感器信息收集与使用

本应用在以下场景中会使用设备传感器，所有传感器数据仅在您使用对应功能时读取，不会上传至远程服务器：

3-A.1 加速度传感器（Accelerometer）

  • 使用目的：检测设备方向变化，支持视频播放时的横竖屏自动切换
  • 使用场景：仅在您使用视频播放功能、且播放器处于全屏模式时读取
  • 使用范围：传感器数据仅在设备本地使用，不会上传或共享
  • 是否可关闭：关闭设备"自动旋转"功能即可停止传感器读取

3-A.2 设备序列号（SN）

  • 收集方式：本应用不主动读取设备序列号。以下第三方 SDK 可能因功能需要收集设备序列号或等效标识符：
  • 华为 AGC 基础服务 SDK：用于华为应用市场服务基础功能（如应用内支付、版本更新），可能收集设备序列号（SN）作为设备标识
  • 华为 HMS 应用内支付 SDK：用于验证购买状态，可能收集设备序列号（SN）用于订单和设备绑定验证
  • 收集目的：设备标识、支付验证、应用版本更新
  • 使用范围：由华为软件技术有限公司收集和使用，详见华为消费者业务隐私声明
  • 重要提示：以上 SDK 均在您同意本隐私政策后才会初始化，未同意前不会收集任何信息

四、信息的存储与保护

  • 本地存储：应用配置、购买状态、主题偏好等数据仅存储在您的设备本地，不会上传至任何服务器。
  • 临时缓存：文件传输过程中产生的临时文件在传输完成后自动清理。
  • 局域网传输：文件及剪切板数据仅在您的局域网内传输，不会经由任何中间服务器。
  • 加密存储：购买状态等敏感信息使用系统级加密存储（Android EncryptedSharedPreferences / iOS Keychain）。
  • 安全措施：我们采取合理的技术措施保护您的信息安全，但请注意互联网环境并非绝对安全。

五、信息共享、转让与公开披露

  • 我们不会出售您的个人信息。
  • 文件内容、剪切板内容等核心数据不会上传至远程服务器，也不会分享给任何第三方。
  • 仅在以下情形下共享必要信息：
    • 为实现本政策第二条所述的第三方 SDK 服务功能；
    • 根据法律法规规定、诉讼争议解决需要，或行政、司法机关依法提出的要求；
    • 为保护您或公众的人身财产安全免遭侵害所必需。
  • 如发生合并、收购或破产清算，我们将要求新的持有您个人信息的公司继续受本政策约束，否则将要求其重新取得您的同意。

六、您的权利

根据相关法律法规，您对您的个人信息享有以下权利：

  • 查阅/更正权：您可以随时修改设备名称等可编辑信息。
  • 删除权：卸载本应用将自动清除所有本地存储的数据。清除缓存可在设置页面操作。
  • 撤回同意权：您可随时在设备系统设置中撤销已授权的权限（如相机、存储权限），或在系统设置中限制广告追踪。
  • 账号注销权：本应用不设账号体系，无需注册登录。卸载应用即视为注销并永久清除所有本地数据。
  • 停止广告展示：购买高级版后将永久停止所有广告展示。

如需行使上述权利，或对我们的数据处理有任何疑问，请通过本政策"九、联系我们"中的方式与我们联系。我们将在 15 个工作日内予以回复。

七、未成年人保护
